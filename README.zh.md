# Notion Flow

[English](README.md) · [中文示例文档](examples/notion-flow-demo.zh.md) · [English example note](examples/notion-flow-demo.md) · [样式样张](examples/notion-flow-style-demo.md)

为 Obsidian 提供 Notion 风格的块编辑体验：移动完整的 Markdown 内容块、用 `/` 插入内容、通过浮动工具栏设置文本格式、增强表格编辑，并为每篇笔记换上精心设计的配色与版式——同时保留纯文本工作流。

> [!NOTE]
> Notion Flow 只增强 Obsidian 内的编辑体验，不连接 Notion，也不提供 Notion 的导入、导出或同步功能。

## 功能概览

- **笔记样式：**九套精心设计的配色方案和六种版式，统一改变插件绘制的一切——标注（Callout）、标题、高亮、表格、引用、列表、待办、分割线、折叠块、分栏、行内代码和代码块，浅色与深色模式皆可。用**切换样式配色…**实时预览。只改变显示，Markdown 不会改变。
- **内容块操作：**拖动段落、标题、带子项的列表、引用、标注、代码块和表格；点击手柄打开块菜单（其中有**块颜色**——文字或背景——以及**移动到…**和**转为页面**），点击 `+` 在下方插入内容。
- **页面：**从笔记属性读取的 Notion 式页面图标与封面，以及按笔记设置的页面字体、小号文字和全宽。
- **框选多个块：**从编辑区空白处拖出选框（或按住 Alt/Option 从任意位置拖动），一次完成转换、复制、剪切、粘贴替换、创建副本或删除。
- **斜杠命令：**分组菜单，用中英文关键词插入标题、列表、标注、折叠块、代码块、表格（`/table4x6` 可直接指定尺寸）、分栏、分割线、公式、图表、图片、视频、日期时间、内部链接、目录（`/toc`）以及模板文件夹中的模板；还可以按名称插入各类标注（`/tip`、`/warning`、`/提示`），或直接上色（`/red`、`/red background`）。
- **折叠块：**用 Notion 式的三角形把任意块收起来——用「/折叠」插入或在块菜单中转换——还能一次折叠或展开全部折叠块。展开状态保存在笔记里，而不是工作区状态里。
- **分栏：**像 Notion 一样让块并排显示——用「/分栏」插入、在块菜单中转换，或把块拖到另一个块的右缘。以普通嵌套标注语法写入，笔记保持可移植。
- **批注：**像 Notion 一样选中文本添加批注——黄色锚点、💬 标记，悬停即显示带「编辑」「解决」的卡片，**查看本笔记的批注**可列出全部批注。批注保存在笔记内部，在其他 Markdown 应用中不可见。
- **格式工具栏：**设置粗体、斜体、下划线（`Cmd/Ctrl+U`）、删除线、文字颜色、高亮和行内代码，也可以清除格式——在代码块内同样可以加粗、斜体、划线和变色。链接在小卡片中编辑——`Cmd/Ctrl+K` 即可打开，Markdown 链接和 `[[双链]]` 都适用，并提供笔记建议。颜色按钮会显示光标处的当前颜色，`Cmd/Ctrl+Shift+H` 重新应用上次使用的高亮。
- **表格工具：**增删、移动、复制、排序、对齐、着色、格式化和移动表格；粘贴电子表格单元格自动生成表格；编辑原始 Markdown 表格时可使用快捷导航。
- **更简洁的实时预览：**优化任务、引用、分割线、行内代码、Mermaid 图表、嵌套块和 Markdown 标记的显示；还没有内容的标题、列表、待办和引用会显示占位提示。
- **白板思维导图：**像思维导图一样延伸、折叠、拖动和调整卡片，导图自动保持整齐、平滑过渡；渐细或折线分支、分支外框、任务进度、演示模式、**+** 按钮、卡片搜索、小地图，一键连接线与关系线、概要括号、标记与编号、点开才显示的卡片笔记和点击即跳转的链接（网页、笔记或另一张卡片）、卡片形状／字号／线宽、精心设计且带深色版本的配色方案（可跟随笔记配色）与自己保存的配色、连续输入、内置指南，笔记与导图双向转换；笔记、图片、链接、带标签的交叉关系和自由卡片仍在同一张画布上。

## 使用要求

- Obsidian 1.13.0 或更高版本——标注颜色依赖 Obsidian 1.13 起改为完整 CSS 颜色的 `--callout-color` 变量，因此本版本需要 Obsidian ≥ 1.13
- 仅支持 Obsidian 桌面端，不支持移动端
- 完整编辑体验需要实时预览模式
- 不需要账号、API Key 或外部服务

## 安装

### 从已发布的 Release 安装

当 [Releases 页面](https://github.com/xinli12/obsidian-notion-flow/releases)存在已发布版本时使用此方式；如果页面尚无可用版本，请按下方步骤从源码构建。

1. 从同一个 Release 下载 `main.js`、`manifest.json` 和 `styles.css`。
2. 新建 `<库>/.obsidian/plugins/notion-flow/` 文件夹。
3. 将三个文件复制到该文件夹。
4. 重启 Obsidian。
5. 打开**设置 → 第三方插件**，按需启用第三方插件，并开启 **Notion Flow**。

### 从源码构建

需要 Node.js 18 或更高版本；CI 使用 Node.js 20。

```bash
git clone https://github.com/xinli12/obsidian-notion-flow.git
cd obsidian-notion-flow
npm install --legacy-peer-deps
npm run build
```

将生成的 `main.js` 与 `manifest.json`、`styles.css` 一起复制到 `<库>/.obsidian/plugins/notion-flow/`，重启 Obsidian，然后在**设置 → 第三方插件**中启用插件。

在**设置 → 编辑器 → 默认编辑模式**中选择**实时预览**，也可以从当前笔记的视图菜单临时切换。

## 快速上手

1. 将[中文](examples/notion-flow-demo.zh.md)或[英文](examples/notion-flow-demo.md)示例文档复制到你的库中，或使用**设置 → Notion Flow → 帮助与示例 → 在库中创建导览笔记**。
2. 使用实时预览打开副本。
3. 悬停到内容块左侧：拖动 `⋮⋮` 移动，点击 `⋮⋮` 打开菜单，点击 `+` 在下方插入新块。
4. 在行首输入 `/`，选择要插入的块类型。
5. 选中文本，打开格式工具栏。
6. 点击已渲染表格中的单元格，打开表格工具栏。
7. 在命令面板中运行**切换样式配色…**，用方向键浏览各套配色与版式；按 `Esc` 即可全部还原。

大多数编辑和外观功能都可以在**设置 → Notion Flow** 中调整。

首次启用时会弹出提示，点击即可打开**快捷键指南**（也可在**设置 → Notion Flow → 键盘快捷键**中打开，或使用**打开快捷键指南**命令）。更新后点击提示会在 Obsidian 内打开**更新内容**：本版本的新功能（每项都有**试一试**按钮）、**在库中创建导览笔记**，以及**在 GitHub 查看发布说明**。**更新内容**和**在库中创建导览笔记**也在**设置 → Notion Flow → 帮助与示例**中。

## 使用 Notion Flow

### 内容块

拖拽手柄会按完整的 Markdown 结构处理内容。列表项会带着嵌套子项一起移动；引用、标注、代码块和表格会作为整体移动。拖动时横向移动指针可选择合法的嵌套层级；只横向拖动可以原地调整缩进。拖到编辑区上、下边缘会自动滚动，按 `Esc` 取消。

单击手柄而不拖动，可打开块菜单：

- **转为**打开子菜单——标题会写出块的当前类型，例如**转为 · 标注**，每一项都标注了对应的组合键——可把块转为正文、标题、列表、待办或引用，也可以把块整体包进标注、折叠块或代码块。包进标注时正文成为框内内容，光标停在空标题行；普通引用会保留自己的 `>` 标记、只在上方补一行标题，因此是「升级」为标注，而不是再嵌一层。
- 把标注、折叠块或多行引用转为标题或列表类时，只有它的**标题**成为新的标题或列表项；其余内容拆框保留——列表项下缩进排列，标题则接在其后作为普通行。选**正文**就是纯粹的拆框，选**引用**则保留为引用，因此标注里的列表和代码块都会原样保留。选中多个块时，所有块一步完成转换。
- **块颜色**给整个块上色：九种文字颜色或九种背景色，外加**默认**，当前颜色会打勾。背景色会铺满整个块的每一行，并跟随配色方案。标题、表格、代码块、图片和标注标题行没有块颜色（标题的文字可用工具栏上色）。块选择工具栏和斜杠菜单（`/red`、`/red background`）提供同样的颜色。
- 上移或下移块、创建副本、复制文本、复制块链接或嵌入（标题按其文字链接，其他块会生成或复用 Obsidian 的 `^块ID`），或删除整个块。菜单项都标注了对应的组合键。
- **移动到…**借助 Obsidian 核心插件「笔记重组」把块移到另一篇笔记，该核心插件关闭时不显示；**转为页面**把块移到一篇新笔记，并在原处留下链接。
- 对标注可选择**标注类型**、**标注颜色**（九种调色板颜色，与类型无关）、**图标…**，或切换**可折叠**。对普通引用选择类型会直接升级为标注。
- 对表格在顶部或底部加行、在左侧或右侧加列，并设置整表对齐、表格底色或格式化源码。
- 对图片，**图片尺寸**提供 25%、50%、75% 和**整栏宽度**（都相对图片所在的栏计算），以及**原始尺寸**；**图片对齐**可选**左对齐**、**居中对齐**或**右对齐**，以 Obsidian 能识别的词写入嵌入语法（`![[image.png|center|480]]`）。也可以直接拖动图片右缘并实时查看像素宽度；宽度以 Obsidian 自己的 `![[image.png|480]]` 后缀写入。

点击 `+` 会在当前块下方插入新块并打开斜杠菜单；在列表项上点击则添加下一项（待办会添加待办），**按住 Alt/Option 点击**则在上方添加。**在下方插入块**（macOS 上为 `Cmd+Option+=`）/ **在上方插入块**（`Cmd+Option+Shift+=`）命令用键盘完成同样的事——笔记开头就是已渲染的标注、表格或代码块时，这是在它上方写字的办法。在 Windows 和 Linux 上这两个命令没有默认组合键（见[命令与快捷键](#命令与快捷键)）。

启用**空行提示**后，正在书写的空行上会显示浅色的「输入 / 插入块」，与 Notion 标注空块的方式一致。它由样式表生成而非插入文本，因此不会写进笔记、无法被选中或复制，代码块内以及已有文字的行上也不会出现。

启用**输入速记**后，Obsidian 没有速记的那几种块，也能像 `-` 生成列表那样由几个字符长出来：输入 `>!` 加空格生成标注，`>!tip`、`>!warning`（或 `>!提示`）可指定类型，结尾加 `+` 或 `-` 则可折叠，`>!toggle` 直接写出 Notion 式折叠块；`[]` 加空格生成待办。中文键盘打出的全角字符同样有效：`【】` 加空格生成待办（`【x】` 为已完成），`》` 加空格生成引用，`>！` 或 `》！` 生成标注（`>！提示`）。紧接在段落下方输入的标注会先空出一行，不会吞掉上面的段落。速记只在正在书写的行尾展开，代码块内不生效；类型无法识别时保持原样（`>!foo ` 就是 `>!foo `）。按一次撤销即可还原为原字符。

启用**用 Tab 调整块层级**后，`Tab` 与 `Shift+Tab` 会让光标所在的块在「横向拖拽」提供的同一组层级之间移动——段落、标题、引用或标注都可以缩进到上方列表项之下，不必再去摸鼠标。可达到的层级与拖拽完全一致：在 Markdown 里，段落下缩进四个空格是缩进代码块而不是嵌套块，Tab 永远不会写出这种缩进。列表项仍交给 Obsidian 自己缩进（它会重排兄弟项的编号，本功能不会），表格单元格仍用表格导航，代码块仍是代码缩进。当某个块无处可去时，`Tab` 保持原有含义。

启用**退格删除列表标记**后，在列表项或待办项正文开头按 `Backspace` 会先去掉标记——该项变成同一层级的普通文本，缩进和引用前缀保持不变，待办会连同复选框和圆点一起去掉——再按一次 `Backspace` 才并入上一行，与 Notion 一致。在标题正文开头按下则一次删除整个 `#` 标记，让标题变回段落。

书写时按 `Esc` 可直接选中光标所在的块——这是用键盘进入块选择的入口。随后 `↑`/`↓` 切换到上一个或下一个块（中间的空行会被跳过），`Shift+↑`/`↓` 扩展选择，`Cmd/Ctrl+Alt/Option+=` 在选区下方插入块（加 `Shift` 为上方），`Enter` 回到该块末尾继续书写，再按一次 `Esc` 清除选择。Vim 模式下 `Esc` 仍归 Vim；候选弹窗、菜单或模态框打开时，`Esc` 也仍归它们。

从行旁空白处拖动可框选多个块；也可以按住 Alt/Option，从编辑区任意位置开始拖动。浮动块工具栏会一次转换所有选中的普通块（表格、围栏代码块和多行引用会被跳过，以免损坏其结构），并提供复制与删除按钮。框选后也支持键盘操作：`Cmd/Ctrl+C` 复制，`Cmd/Ctrl+X` 剪切，`Cmd/Ctrl+V` 用剪贴板内容替换选中块，`Cmd/Ctrl+D` 创建副本并选中，`Cmd/Ctrl+A` 扩展为全选所有块，`Backspace`/`Delete` 删除。按 `Esc` 或点击 × 可清除选择。`Shift+点击`某一行可把选择扩展到该行；拖动任意已选中块的手柄会把整个选区作为一个整体移动，放下或用键盘移动后会有短暂的落点闪烁提示块去了哪里。块选择模式下的全部按键见[命令与快捷键](#命令与快捷键)。

### 斜杠命令

在行首、空白字符后，或直接在中日韩文字后输入 `/`（全角 `／` 同样触发）。无论界面语言是什么，都可以使用中英文关键词搜索，中文名称还支持拼音全拼和首字母（`/zw` → 正文，`/yjbt` → 一级标题，`/lianglan` → 两栏）。每个菜单条目显示图标、名称、一行说明和对应语法。

未输入关键词时，菜单按**基础块**、**列表**、**标注与折叠块**、**媒体与表格**、**高级**和**日期**分组，最上方是最多三项**最近使用**。日期类条目会预览将要写入的内容。

可用项目包括 `/h1`、`/h2`、`/h3`、`/bullet`、`/number`、`/todo`、`/quote`、`/callout`、`/toggle`、`/cols2`、`/cols3`、`/code`、`/table`、`/divider`、`/image`、`/video` 和 `/link`，以及**正文**（变回普通段落）、**公式块**与**行内公式**（LaTeX）、**图表**（Mermaid 代码围栏）、**日期**、**时间**、**日期和时间**、**明天**、**昨天**——后几项按**日期格式**和**时间格式**设置写入当前日期或时间。

有些条目只在搜索时出现：

- **按名称插入标注：**`/tip`、`/warning` 或 `/提示` 会给出**标注 · 提示**等条目——Obsidian 的十三种类型都有。
- **颜色：**`/red` 或 `/红色` 给块的文字上色；`/red background`、`/红色背景` 或 `/bg red` 给块加背景色（见[内容块](#内容块)中的**块颜色**）。

**目录**（`/toc`）先写入 `<!-- nf-toc -->` 标记，再写入由 `[[#标题]]` 链接组成的嵌套列表。链接遵循 Obsidian 自己的标题链接规则，重名的标题会经由上级标题链接（`[[#第 2 周#笔记|笔记]]`）。实时预览中，这个标记显示为一枚小小的**目录**标签，点它的刷新按钮——与**刷新目录**命令一样——会一步（一次撤销）重写整个列表。笔记中没有标题时会弹出提示。

**模板。**开启核心插件「模板」并设置模板文件夹后，每个模板都是一个单独的条目**模板 · 名称**，由「模板」插件自己插入，因此 `{{date}}`、`{{title}}` 和笔记属性的行为与原来完全一样。模板超过八个时，只显示一个**模板**条目，它会打开 Obsidian 的模板选择器，搜索仍能找到每个文件。没有设置模板文件夹时，**模板**条目会执行 Obsidian 自己的「插入模板」，它会提示尚未配置模板文件夹；核心插件「模板」关闭时，则提示你先去设置。

用鼠标或 `Enter` 选择**表格**后会打开最大 10 × 10 的尺寸网格。可以在网格中拖动、用方向键调整，或直接键入尺寸：数字键设置列数，`Shift`+数字设置行数（`0` 表示 10），然后按 `Enter` 插入。在命令里直接写上尺寸，如 `/table4x6`（或 `/表格4×6`、`/4x6`），会跳过网格直接插入 4 列 6 行的表格。代码围栏内不会触发斜杠菜单。

### 文本格式

选中编辑器文本即可显示浮动工具栏，支持：

- 粗体、斜体、下划线、删除线和行内代码。**切换下划线**为 `Cmd/Ctrl+U`；删除线和行内代码沿用 Obsidian 自己的命令，没有默认组合键。
- 文字颜色和高亮色板——九种低饱和墨色，跟随配色方案，浅色/深色模式各有一套。文字颜色和高亮按钮会显示光标处的当前颜色（按钮下方出现色条、对应色块打勾），因此在已着色的文字中间换色或**移除颜色**都不必精确重新选中。每个色板最前面是**上次使用**色块；`Cmd/Ctrl+Shift+H`（**应用上次使用的高亮**）和**应用上次使用的文字颜色**命令可以不打开工具栏直接套用，**文字颜色…**和**高亮颜色…**命令则用键盘打开工具栏的颜色行
- LaTeX 公式同样可以上色：选区里的 `$…$` 或 `$$…$$` 会在定界符内部着色（`\class{mjx-…}`），公式仍然是公式，不会变成字面的美元符号
- Markdown 链接和 `[[双链]]` 都在小卡片中编辑：可通过链接按钮、`Cmd/Ctrl+K`（Obsidian 的「插入链接」快捷键，开启浮动工具栏时会打开这张卡片；在代码块内仍执行 Obsidian 自己的行为）或**插入或编辑链接**命令打开。卡片中有链接文字和目标两栏，目标栏会建议库中的笔记；提供**打开**（仅当目标存在时）与**取消链接**。双链保持双链形式，别名作为链接文字编辑；含空格的 Markdown 链接目标会自动用 `<…>` 包裹
- 对选区添加批注（💬）
- 清除格式（`Cmd/Ctrl+\`）：清掉与选区相关的所有格式——粗体/斜体（`*` 与 `_` 均可）、删除线、高亮、行内代码，以及隐藏 HTML 标签完全在选区之外的颜色和下划线。标记永远整对移除，部分选中也不会留下孤立的 `**` 或 `</span>`。批注是内容而非格式，会完整保留。

选区跨越多个段落或列表项时，格式会逐行分别套用，标记不会跨越块的边界。在分栏内，`Cmd/Ctrl+B`、`I`、`K`、`U` 和 `\` 只作用于当前栏。

绑定了快捷键的工具栏按钮会在提示中显示快捷键；右键点击会先收起工具栏，给 Obsidian 的右键菜单让位。

启用**粘贴 URL 生成链接**后，在选中的单行文本上粘贴 `http://`、`https://` 或 `obsidian://` URL，会自动生成 `[文本](链接)`。启用**粘贴 URL 自动获取标题**后，未选中文本直接粘贴 URL 会先立即插入原始链接，随后在后台获取网页标题并升级为 `[网页标题](链接)`；无法访问网页时保留原始 URL，粘贴到代码环境时不做任何处理。

在代码块内，工具栏会自动改用 HTML 标签（`<b>`、`<i>`、`<s>`、`<u>` 与颜色 span），因为 Markdown 标记在围栏代码中只是普通文本。这些标签在实时预览中隐藏、在阅读视图中渲染为带样式的代码；行内代码和链接按钮在代码块内会置灰（在代码中没有意义）。在代码块内**清除格式**只移除这些标签——代码里真实的 `*`、`` ` `` 等字符绝不会被误删。

### 代码块

启用**代码块编辑增强**后：

- 按 `Enter` 续行时保持当前行缩进——嵌套在（深层）列表中的代码块，每个新行都自动对齐到列表的内容列。
- 在代码文本开头按 `Backspace` 一次回退一级缩进，而不是逐字符删除。
- 在刚输入的、未闭合的 ` ``` ` 行末按 `Enter` 会自动补全闭合围栏并把光标放进块内，代码块不会再"吞掉"下方的整篇笔记。
- 按 `Cmd/Ctrl+Shift+Enter`（**跳出代码块**命令，可在快捷键设置中重新绑定）跳出代码块，落到其下方一个缩进正确的新行（若缺少闭合围栏会先补上）。代码块位于笔记末尾时，在最后一行按 `↓` 会在它下方新建一行；在列表中使用 `/code`，代码块会保持在列表项之下的缩进。
- 点击语言栏中的箭头可以折叠或展开代码正文；状态写入笔记，重新加载和同步后仍会保留。
- 点击语言栏中的语言名称，会打开可搜索的语言选择器：约 40 种语言并配有易读的名称，支持别名（`js` → JavaScript，`py` → Python），最近用过的语言排在最前，另有**无语言**，也可以直接输入任意其他语言标记。选择与当前相同的语言（例如对 `js` 选 JavaScript）不会做任何改动。实时预览中这个标签替代了整个 ` ```lang ` 标记，因此这里就是修改语言的地方；信息串的其余部分（` ```js title=x `）保持不动。
- 点击语言栏中的复制按钮，把代码块的内容复制到剪贴板：引用标记、以及所在列表或标注带来的缩进都会去掉，代码的自身缩进保留，粘贴出来就是可直接运行的代码。阅读视图用的是 Obsidian 自带的复制按钮，这个补上的是实时预览里缺的那个。
- 引用和标注里的代码在编辑时也有语法高亮。Obsidian 编辑器不会把引用内的 ` ``` ` 识别成代码块（整段代码被当作一长串普通文本），插件因此直接调用库里自带的语言模式，输出与顶层代码块完全相同的 token 类名——配色仍来自你的主题，包括本插件的代码配色主题。
- 在块手柄菜单中可以添加或编辑说明文字；caption 会贴在代码卡片下方，并随代码块一起移动、复制和删除。
- 图片、嵌入块和表格也提供**添加说明文字**，caption 直接显示在图片或表格下方，并随该块一起移动、复制和删除。

### 标注与引用

启用**标注与引用编辑增强**后：

- 在引用或标注内按 `Enter` 会自动续写 `>` 标记；在块**末尾**只有 `>` 的空行上按 `Enter` 会退出块（嵌套时逐层退出），在标注末尾连按两次即可离开，与 Notion 一致。如果这个空行下面还有内容，就谈不上“退出”——`Enter` 只是再加一个空行，块保持完整。
- 在行首正文位置按 `Backspace` 会一次移除一层 `>` 标记，而不是逐字符删除——但只在"离开这个块"讲得通的位置。在引用/标注的**最后一行**按下时照旧脱掉一层；在容器的**第一行**按下时会整块拆开，因为只把标题行的标记去掉会让下面所有行变成孤儿；在**中间任意一行**按下则并入上一行，也就是 `Backspace` 在行首本来的含义。插件自己写入的结构行——`[!nf-cols]` 标题、两栏之间的分隔行——会直接吞掉这个按键，避免误触把分栏拆散。
- 在引用或标注内粘贴多行文本时，每一行都会自动补全前缀，块不会被撕开；富文本会先转成 Markdown，文件粘贴保持 Obsidian 原有行为。
- 点击已渲染的标注会把光标直接放到点击处开始编辑，替代 Obsidian 原生"第一次点击选中整块"的行为；拖拽仍可选中整块。
- 光标位于标注内时，直接在稳定的渲染外观中编辑：`>` 与 `[!note]` 等结构标记由图标和固定间距代替，不会突然展开成源码；按类型着色的背景、圆角、标题与正文位置保持不变。
- 在实时预览中点击已渲染标注的图标，会打开它的菜单：Obsidian 内置的十三种类型、**标注颜色**、**图标…**、**可折叠**和**转为引用**。块手柄菜单同样提供类型、颜色、图标和折叠；在那里对普通引用选择类型会直接升级为标注。
- **图标…**打开可搜索的图标选择器：24 个 Lucide 图标、一组表情（最近使用的排在前面），以及恢复类型自带图标的**默认图标**。选择保存在标注的元数据中——图标写作 `nfi-<名称>`（`> [!tip|nfi-rocket]`），表情则写作 `nfi-emoji`，表情本身放在标题开头——其他应用会忽略它。
- **标注颜色**可给任意标注换上九种调色板颜色之一，与类型无关。颜色以 `> [!tip|nf-green]` 这样的元数据写在类型之后——Obsidian 和其他应用都会忽略它，同一位置的栏宽信息也会保留。
- **标注样式**——**带标题栏**、**扁平（类 Notion）**、**侧线**、**柔和卡片**、**描边**、**极简（仅图标）**或**渐变标题栏**——现在位于[笔记样式](#笔记样式) → **自定义各组件**，默认跟随版式。无论哪种样式，阅读视图中悬停标注都不再变色；只有标题的标注标题下方也不再有分隔线。
- 编辑代码块时，开头围栏显示为紧凑的语言标签，结尾围栏折叠为卡片边缘；光标进入后也不会出现 ``` 源码。引用的 `>` 标记同样由稳定占位替代，正文不会左右跳动。
- **引用里的代码块和列表**边打边渲染。Obsidian 的实时预览把引用内的每一行都当作普通引用文本——代码围栏保留原始的 ``` 标记、列表只显示一个字面的减号，尽管阅读视图两者都能正常渲染——所以代码块底色和列表符号由 Notion Flow 自己绘制。

### Mermaid 图表

启用**更简洁的所见即所得渲染**后，实时预览和阅读视图中的 Mermaid 图表会使用适配当前主题的卡片式画布。流程图、时序图、子图、注释、甘特图和饼图拥有更清晰的视觉层级。宽图会保留可读字号并支持横向滚动，不再被压缩成难以辨认的缩略图；聚焦图表后可使用键盘或触控板滚动。Mermaid 源码不会被修改。

### 分栏

启用**分栏**后，块可以像 Notion 一样并排放置：

- 输入「/分栏」（或 `/cols2`、`/cols3`），选择**两栏**或**三栏**；新的分栏行会直接在可视化分栏编辑器中打开，可立即输入。
- 用手柄把一个块拖到另一个顶层块的**右缘**——出现竖向的强调色指示条即为目标——放下后两个块并排显示。拖放到已有分栏行上会追加一栏。
- 每个已渲染的分栏行右上角都有一个小分栏按钮（悬停时更明显），点一下即可**添加一栏**、调**栏宽**或**拆开分栏**；块手柄菜单提供相同操作，并对任意顶层块提供**转为分栏**。
- 直接拖动两栏之间的分隔线即可调宽，拖动时会显示实时百分比；整次拖动只产生一条撤销记录。用 Tab 聚焦分隔线后，←/→ 每次调整 1%（按住 Shift 为 5%），双击恢复均分。
- 悬停单独一栏会出现该栏的 **⋯** 菜单，可在左右添加新栏、左右移动当前栏或删除。删除非空栏前会确认；两栏删去一栏后，保留内容会自动拆回普通块。
- 用标注元数据固定栏宽：`> > [!nf-col|30]` 占据整行的 30%（有效值 10–90），未指定宽度的栏平分其余空间；也可以在块菜单的**栏宽**子菜单里选预设（均分／左窄／右窄）。布局按 Obsidian 窗格宽度响应，低于 560px 时整组纵向堆叠，三栏不会出现不稳定的“2+1”换行。
- 块菜单里的**拆开分栏**可以把分栏行还原为依次排列的普通块。
- 空栏会显示虚线 **+** 占位，可见且可点击；悬停已渲染的分栏行会勾勒出每一栏的边界。
- 点击已渲染的一栏即可就地编辑，不再暴露整行的 `> >` 结构前缀。当前栏进入干净编辑态，其他栏仍以阅读态显示作为上下文；点击另一栏预览即可切换，用源码按钮查看原始语法，按 `Esc` 或勾选按钮完成。撤销／重做仍统一属于当前笔记。在栏内，`Cmd/Ctrl+B`、`I`、`K`、`U` 和 `\` 只作用于当前栏，输入速记和 `Backspace` 规则也与在笔记中一样有效。
- 在栏内（或任何引用/标注内）使用斜杠命令时会保留 `>` 标记，插入的代码块、表格、标注都留在原栏中。
- 分栏以嵌套标注语法写入——`[!nf-cols]` 包裹若干 `[!nf-col]` 子块——在其他 Markdown 应用中显示为普通嵌套引用，笔记不会被插件绑定。
- 需要时仍可在源码模式查看可移植的 `[!nf-cols]` / `[!nf-col]` 语法；结构行以淡色显示，因为它们是结构而非正文。
- 分栏源码现在按真实的“行／栏”结构解析：代码围栏中的 `[!nf-col]` 不会被误认成新栏，混合 Tab 与空格的缩进不会在转换时变形，空栏中的 Enter／Backspace 不会删坏结构标记，栏内代码块和表格的键盘编辑也会保留栏前缀。

### 折叠块

开启**折叠块**后，任意块都能藏到一个三角形后面：

- 用「/折叠」新建一个折叠块，或在任意块的手柄菜单里选择**转为** → **折叠块**——该块的第一行成为标题，其余部分成为折叠起来的内容。
- 点三角形收起或展开。与 Obsidian 的列表折叠不同，展开状态会写回笔记（`+` 展开、`-` 收起），因此重载、同步和换设备后都还在。
- 折叠块是"三角形 + 正文"，不是彩色方框：没有底色、没有边框、没有图标。内容可以是任何东西——段落、列表、代码块、图片，以及再嵌套的折叠块。
- 光标在块内部时，`[!nf-toggle]±` 这段结构会被同一个三角形替代，所以编辑折叠块的内容时它看起来仍然是折叠块；把光标移到标题行即可编辑原始标记。
- 已有折叠块的块菜单提供**收起** / **展开**和**折叠本页全部** / **展开本页全部**；**转为** → **引用**可把它变回普通引用。
- 在新折叠块的最后一个空行按 `Enter` 即可离开折叠块，与离开引用一样。
- **折叠全部折叠块**、**展开全部折叠块**和**折叠或展开全部折叠块**一次设置笔记中所有折叠块和可折叠标注的 `+`/`-`，只算一步撤销。最后一个在 macOS 上为 `Cmd+Option+T`；其他系统没有默认快捷键，因为 `Ctrl+Alt` 在许多键盘布局中就是 AltGr。只有笔记中含有折叠块或可折叠标注时才会提供这些命令。
- 以 `[!nf-toggle]` 标注语法写入，在其他 Markdown 应用中显示为普通引用，笔记保持可移植。如果想要保留标注颜色的可折叠方框，「/可折叠标注」仍然写出 `> [!note]-`。

### 批注

启用**批注**后，可以像 Notion 一样选中文本加注释：

- 通过浮动工具栏的 💬 按钮、**添加批注**命令或 `Cmd/Ctrl+Shift+M` 添加批注。批注针对单行内的选区。
- 锚文本以黄色高亮，其后跟一个小 💬 标记。悬停任一处即显示带「编辑」「解决」的小卡片（关闭**批注悬停卡片**后改为普通提示）；点击标记打开编辑器，其中会引用锚文本，并提供「取消」「保存」和「解决」（解决后标记消失、正文保留）。
- 阅读视图中锚点保持高亮，悬停显示批注。
- **查看本笔记的批注**以可搜索的列表列出每一条批注——锚定的文字和批注内容。`Enter` 跳转到锚点，`Cmd/Ctrl+Enter` 解决该批注并保持列表打开。在阅读视图中运行时会先切换到实时预览。
- 批注以 `<span class="nf-cmt" data-nf-cmt="…">正文</span>` 的形式保存在笔记内——在其他 Markdown 应用中锚文本正常显示、批注内容不可见。清除格式不会移除批注；点击批注标记选择「解决」即可去掉其标记。

### 表格

在实时预览中第一次点进已渲染的单元格，表格上方就会浮现工具栏，提供行列操作、当前列对齐、单元格或表格底色、格式化和删除。按 `Alt+F10` 聚焦工具栏，再用左右方向键在按钮之间移动。工具栏的 **…** 按钮收纳其余操作：创建行副本、上移/下移行、左移/右移列，以及按当前列升序或降序排序表体（表头不动，光标跟随所在行）。

在编辑器的右键菜单中，所有表格操作都收在一个**表格**子菜单里，**块菜单…**仍留在顶层。

**表格编辑增强**设置只作用于源码模式中的原始 `|` 表格，或仍未渲染的表格：

- `Tab` / `Shift+Tab` 在可编辑单元格之间移动。
- `Enter` 移动到下一行的同一列。
- 从最后一个单元格继续导航会自动追加一行。
- 输入 `| 名称 | 数量` 这样的表头后按 `Tab`，会自动创建分隔行和第一行表体。
- 在空的最后一行按 `Enter` 会移除该行并离开表格。

命令面板也提供相同的结构操作——所有表格命令都以**表格：**开头（在上方/下方插入行、在左侧/右侧插入列、删除行/列、上移/下移行、左移/右移列、创建行副本、按列升序/降序排序），原始表格的右键菜单亦然。**表格：格式化**会按中日韩字符的显示宽度对齐各列。

启用**将粘贴的表格单元格转为表格**后，在空行粘贴从 Excel、Numbers 或 Google 表格复制的单元格（制表符分隔的文本）会自动变成 Markdown 表格，光标落在表格下方；命令面板中的**表格：将剪贴板粘贴为表格**可随时手动执行。

### 页面

Notion Flow 为笔记提供 Notion 式的页面头部，以及按笔记设置的页面样式。

- **页面图标与封面。**把鼠标移到笔记标题上方，会出现**添加图标**和**添加封面**。图标是一个表情，从常用表情网格（含最近使用）中选择，**移除图标**可去掉它。**添加封面**会立即给页面加上一张内置的渐变封面；悬停封面可**更换封面**——其他渐变（会跟随配色方案）、**从库中选择图片…**和**移除封面**——图片封面还可以**调整位置**。
- 图标和封面保存在笔记属性中：`icon`、`cover`（`[[图片]]` 链接或 CSS 颜色）、`cover-style`（渐变的 id）和 `cover-y`（图片的纵向位置）。其他读取 `cover` 的工具看到的仍是图片。如果不想看到这几行属性，可以把 Obsidian 的**设置 → 编辑器 → 笔记属性**设为**隐藏**。
- 页面头部由**页面图标与封面**控制（位于「外观」，默认开启），在实时预览和阅读视图中都可用。启用 Banners、Pixel Banner 或 Iconize 插件时，它会自动让位。
- **页面样式。**笔记的「更多选项」（⋯）菜单中有**页面样式**：字体可选**默认**、**宋体**、**等宽**或**楷体**，还有**小号文字**和**全宽**。同样的选项也是命令：**页面字体：默认**、**页面字体：宋体**、**页面字体：等宽**、**页面字体：楷体**、**切换小号文字**和**切换全宽**。它们写入笔记的 `cssclasses` 属性，分别为 `nf-serif`、`nf-mono`、`nf-kai`、`nf-small` 和 `nf-wide`；那里原有的其他 class 会保留。

### 白板

可以先将[白板示例](examples/canvas-flow-demo.canvas)复制到库中体验。

在**设置 → Notion Flow**中开启 **白板增强**，打开 `.canvas` 文件。顶部工具栏按用途分组：**新主题／子主题**、**同级主题**、**连接**；**布局**、**样式**、**标记**、**笔记**、**链接**；折叠、聚焦；查找、演示；**更多**和 **?** 指南。常用按钮带文字标签（窄窗口只显示图标）；没有选中卡片时第一个按钮是**新主题**，在视野中央新建一张卡片，选中卡片后它变为**子主题**；聚焦分支时**聚焦**变为**显示全部**。选中卡片上方的白板浮动菜单只保留最常用的动作（子主题、同级主题、连接、折叠、标记、笔记、链接），卡片右键菜单和命令面板提供相同的操作。点工具栏右端的 **?** 打开**白板导图指南**：按键、手势和每个组件的用法都在里面。

**思维导图。**在一张独立卡片上按 `Tab`，或点击它周围的 **+** 按钮，它就成为思维导图的中心并朝你点的方向长出第一个分支；也可以点工具栏的**布局**打开布局面板（和样式面板一样带缩略图），把任意卡片的树整理成八种结构之一，切换结构时保留导图的阅读顺序：

- **思维导图**：分支分布在中心两侧。
- **逻辑图**（向右或向左）与**组织结构图**（向下或向上）：所有分支朝一个方向生长。
- **树状图**：挂在中心下方的缩进大纲，像文件树一样。
- **时间轴**：中心是起点，主干分支是轴线上依次排开的事件，每个事件的细节列在其下方。**纵向时间轴**则让事件沿页面向下排列，细节向右展开。

布局面板还提供更灵活的选项：**此分支**给选中的分支单独指定结构（逻辑图、组织结构图、树状图、时间轴等），它的子树在整张导图里都保持这一结构，可以像 XMind 一样在思维导图里嵌一段大纲或一条时间轴，记录在分支卡片的 `nfBranch` 字段；**子主题**决定子主题相对父主题**居中**还是**顶端对齐**，记录在中心卡片的 `nfAlign` 字段；**间距**和**自由布局**也在这里。
导图会自动保持整齐：

- **键盘或鼠标延伸：**`Tab` 新建子主题，`Enter` 新建下一张（在下方新建同级主题，中心主题则新建分支），`Shift+Enter` 在上方新建同级主题；点主题边缘的 **+** 新建子主题。写完后新主题卡片自动贴合文字。
- **连续输入：**在卡片中输入时，`Enter` 结束编辑并保持选中，再按 `Enter` 新建下一张、按 `Tab` 新建子主题——输入、`Enter`、`Enter`、再输入，像思维导图软件一样一口气敲出整棵树，全程不用鼠标。`Shift+Enter` 换行；在列表、引用、表格和代码中 `Enter` 照常续写（列表在空项上按 `Enter` 结束，再按一次 `Enter` 结束卡片编辑）。输入时按 `Tab` 直接结束并新建子主题，`Shift+Tab` 把主题升一级并继续输入，`Esc` 在任何位置都能结束编辑，`Cmd/Ctrl+Enter` 也可以（光标在链接上时则打开链接）。输入时工具栏照常可用：点击工具栏会先结束当前主题的编辑，再执行操作。结尾多余的换行和空行会自动去掉。选中卡片后按 `空格` 开始编辑并把光标放到末尾，按 `F2` 则选中全部文字方便替换；新建后留空的卡片会在结束编辑时自动消失，并重新选中它的来源卡片，不留空白卡片。编辑器的占位提示为「输入主题…」。输入法组字时不会被打断。可在设置中关闭**白板连续输入**。
- **舒适编辑：**卡片在原位编辑，保持画布缩放和卡片自身的外观——大小、颜色、字体和对齐都不变——开始编辑时不会突然放大、缩放或移动。只有文字放不下时卡片才顺势变大：单行主题先随文字加宽再换行，多行时卡片向下（朝远离父主题、有空位的一侧）变高，删除文字后随之收回。结束编辑后保留所需空间：导图主题贴合文字，自由卡片保留长高后的高度，但不会盖住下方的卡片。只打开再关闭不会改写尺寸。导图文字修改后按阅读比例适配宽高，适度换行并保留横向留白，长内容限制在 480×640 内并可滚动；图片、表格和代码保留较宽的阅读空间。在设置的**卡片尺寸**中选择**宽松／紧凑／保留手动宽度**。
- **层级字体：**中心主题更大、更粗，分支随层级逐步缩小并减轻字重；按默认 16px 正文字号，依次为 24 / 20 / 17 / 16 / 15px，更深层级保持 15px。字号跟随 Obsidian 的正文字号设置，编辑和阅读一致；多段笔记使用更柔和的字号与字重。调整父子关系时，卡片随新层级重新适配尺寸。
- **配色方案：****样式**面板的**配色方案**提供 23 套精心设计、各带深色版本的方案，分为四组——**清雅**：柔雾、海盐、樱花、马卡龙、莫兰迪、北欧、玫瑰松；**自然**：森林、落日、手账、国色、敦煌、复古；**缤纷**：多彩、极光、主题色、猫咖粉彩、午夜霓虹、糖果；**专注**：墨色、水墨、商务、清晰对比。一键搭配配色、外观、连线和间距，也可以只应用配色。新分支自动延续配色，手动颜色优先，一步撤销；**关闭自动配色**随时恢复主题色。**存为我的配色**把当前导图的配色和样式保存到**我的配色**（用**删除配色**移除），保存在插件设置中。每套方案也都是一条命令：**白板：配色方案 · …**加方案名。
- **导图跟随笔记配色：**开启**导图跟随笔记配色**（默认开启）时，没有自己配色方案的导图会使用与[笔记配色方案](#笔记样式)配套的方案，样式面板最前面会固定一个**跟随笔记配色**方块。这只改变显示：不会写入 `.canvas` 文件，为导图选定的方案始终优先。
- **空白画布：**空白画布会显示配色方案方块，点一下即以该方案开始一张新导图。
- **分支配色：****为此分支上色…**先列出导图自己的色调和**最近使用**的颜色，再列出白板自带的**白板颜色**（写入的颜色不会随之后的浅色/深色切换而变化）。
- **折叠分支：**点分支线上的小圆点（或 `Mod+/`）折叠；折叠后的卡片显示隐藏了多少张卡片，并呈叠放效果。折叠状态保存在文件中。
- **像导图一样拖动：**拖动卡片时整个分支随之移动；拖过同级卡片即调整顺序，放到另一张卡片上即改挂到它下面；拖动中心卡片会带着整张导图移动。
- **安全删除：**删除卡片时保留其子主题，它们会接到最近的上级卡片上；并自动选中接替它位置的卡片，键盘操作可以接着进行。
- **平滑动画：**导图重排、折叠或展开时，卡片平滑移动到新位置；展开的卡片从折叠它们的卡片中“长”出来。
- **每次自动调整都与引起它的操作合并为一步撤销**，撤销和重做不会被重新整理。
- **样式：**每张导图可以在工具栏的**样式**菜单中单独选择外观，否则使用设置中的默认样式。**简洁**：中心主题着色，主干分支是柔和的圆角块，子主题是渐细分支线上的纯文字；**卡片**：每个主题都保留卡片外框；**鲜明**：中心和主干为实色填充，没有颜色的主干自动依次使用调色板颜色（只用于显示，不写入文件）；**极简**：只有文字和连线；**柔彩**：无描边的柔和色块；**渐变**：带光晕的渐变主题。**分支配色**为每条主干写入一种颜色，**清除分支配色**将其移除；**布局**菜单中还可设置导图间距：紧凑、标准或宽松。
- **连线：****样式**菜单还能选择导图分支的画法——**渐细**（从中心伸出时粗、末梢细，像手绘的树枝）、**曲线**（白板原生）、**折线**（直角圆弯，同级分支共用主干）或**直线**。**自动**让思维导图和逻辑图使用渐细连线，组织结构图、树状图和时间轴使用折线。选中卡片时，它回到中心的那条路径会柔和发光。
- **外框：****样式 → 外框**给一个分支加上 XMind 式的浅色虚线外框。导图会为外框留出空间，分支增减、折叠、动画和拖动时外框随之变化；外框可以嵌套。
- **展开到第 N 层：****更多 → 展开到第 1/2/3 层**一步把导图收到主干（或更深一层），**展开全部分支**恢复全部。

**超越思维导图。**

- **连接线：**选中一张卡片后点工具栏的**连接**（浮动菜单和右键菜单里也有），再点要连到的卡片，就画出一条线，画的过程中有虚线预览；`Esc` 或点空白处取消。先选中两张或更多卡片（Shift+点击）再点**连接**，会按选中顺序依次相连。也可以像白板原生那样，把鼠标移到卡片边缘，拖动出现的小圆点到另一张卡片。新画的线会被选中，双击可以加文字。
- **关系线：**导图卡片之间（或导图与自由卡片之间）的连线是关系线：虚线显示，记录在连线的 `nfRelation` 字段，不会把卡片拉进导图或改变分支结构；*带标签*的连线同样是关系线。导图因此可以指向画布任意位置的笔记、图片或卡片，而不会被打乱结构。自由卡片之间则是普通的箭头。
- **标记：**工具栏的**标记**打开标记面板：优先级 1–5（同一卡片只保留一个）、状态（完成、进行中、受阻、注意、疑问、想法）、六色旗帜、一组符号，以及**表情**区（输入任意表情，保留最近使用，每张卡片最多三个）。选中多张卡片可一起添加，面板保持打开以便连续设置，**清除**一键去掉。标记显示在卡片左上角，随缩放保持大小，保存在卡片的 `nfMarkers` 字段。
- **笔记：**给任意卡片挂一段平时看不见、需要时点开的笔记，和 XMind 一样。选中卡片后点**笔记**（工具栏、浮动菜单或右键菜单），或按 `F4`，直接输入——支持 Markdown，边写边保存；`Esc` 或 `Mod+Enter` 关闭，整段笔记算一步撤销。有笔记的卡片右下角会出现一个小笔记图标：点它，笔记就在卡片旁展开，按 Obsidian 笔记的方式渲染——标题、列表、任务、标注、表格、代码、公式，链接可以直接点（按住 `Mod` 悬停可预览）；勾选任务会写回笔记。双击文字或点铅笔进入编辑，垃圾桶删除笔记。一张卡片可以挂多条笔记：按 `Shift+F4`、右键菜单的**再添加一条笔记**，或点笔记面板顶部的 **+** 即可再写一条；面板里各条笔记上下排列，每条都有自己的铅笔和垃圾桶，笔记图标上会显示条数。平移、缩放画布时笔记跟着卡片走，点别处或按 `Esc` 收起。查找（`Mod+F`）也会搜索笔记内容，只读白板上也能查看，**复制分支为大纲**／**分支导出为笔记**会把笔记作为引用放在对应主题下。保存在卡片的 `nfNote` 字段（一条是字符串，多条是列表）。
- **链接：**给卡片加一个点击即跳转的链接：网页、库里的笔记（或其中某个标题）、同一白板上的另一张卡片。选中卡片后点**链接**或按 `Mod+K`：粘贴网址，或输入文字搜索库里的笔记（输入 `笔记名#` 列出它的标题）和本白板的卡片，`Enter` 选第一项。一张卡片想加几个链接都行：`Mod+K` 会再加一个，并把卡片已有的链接列在最前面——选中其中一个即可修改或移除。每个链接在卡片右下角都有自己的图标——地球是网页、文档是笔记、准星是卡片（超过三个时，最后一个图标会列出全部链接）：点它就在浏览器里打开网页、打开笔记（`Mod+点击` 在新标签页打开，按住 `Mod` 悬停可预览），或跳到那张卡片，途经的折叠分支会自动展开。右键某个图标可以打开、复制、编辑或移除这个链接；导出大纲时第一个链接会包在主题文字上。保存在卡片的 `nfLink` 字段（`https://…`、`[[笔记#标题]]`，或 `#` 加卡片 id；多个时是列表）。
- **在卡片文字里链接其他卡片：**编辑卡片文字时，输入 `[[^` 再输入另一张卡片名字里的几个字——或按 `Mod+Shift+K`，或右键选**链接到卡片…**——就会写入 `[[#^id|名称]]`（选中的文字会成为链接文字）。在选中的卡片上点这个链接，或编辑时在链接上按 `Mod+Enter`，就会跳到那张卡片；鼠标停在链接上时，目标卡片会亮起虚线框。卡片右键菜单的**复制卡片链接**可以复制一条链接，粘贴到本白板任意卡片的文字里。导出大纲和笔记时只保留名称。
- **编号：****更多 → 编号**（样式面板的**分支**一节也有）给导图显示 1、1.1、1.2 这样的层级编号，按阅读顺序自动更新；只用于显示，开关记录在中心卡片的 `nfNumbering` 字段。
- **概要（总结括号）：**选中一个或多个相邻的同级分支，点工具栏的**概要**（浮动菜单、右键菜单、样式面板和命令面板里也有），导图会在这些分支的外侧画一个括号，括号尖端指向一张新的概要卡片，直接输入概要内容即可。括号跨越所覆盖分支的整个范围（含它们的子分支），概要卡片居中放置，比分支还高时会自动让出空间；折叠父主题时括号和概要一起隐藏，拖动分支时一起移动，删除中间的分支时括号自动收缩。再次选中概要卡片点**概要**即可移除。概要记录在卡片的 `nfSummary` 字段（父主题及覆盖范围的首尾分支），不带连线，因此不会成为分支。
- **卡片形状、字号与线宽：****样式**面板新增**卡片形状**（圆角、胶囊、直角、下划线）、**字号**（小、标准、大）和**线宽**（细、标准、粗），悬停即可预览，每张导图各自记录；设置中可分别设定默认值。部分配色方案自带形状（樱花、马卡龙为胶囊，墨色为下划线，商务为直角）。
- **白板背景：**设置中的**白板背景**可在 Obsidian 默认点阵、淡点阵和纯色之间切换。
- **笔记与导图互转：****由笔记生成导图**把笔记的标题和列表展开成导图，中心主题链接回原笔记；**分支导出为笔记**把分支写入白板所在文件夹的新笔记。选中导图卡片后粘贴 Markdown 列表，直接生成分支；**列表展开为分支**可把卡片自身的列表展开；**复制分支为大纲**把分支以嵌套列表复制到剪贴板（文件卡片转为链接，待办保持为待办）。
- **查找任意卡片：**`Mod+F` 在画布内打开查找栏：匹配的卡片高亮、其余变淡，计数显示「第 n / N 个（k 个已折叠）」，`Enter`/`Shift+Enter` 逐个跳转（折叠的上级会自动展开），`Esc` 清除。**更多 → 查找卡片**（`Mod+Shift+F`）是搜索列表，同样能找到折叠分支中的卡片。
- **小地图：**画布有内容超出屏幕时，角落出现全局缩略图，点击或拖动即可快速移动视野；可在工具栏中开关。
- **与自由画布共存：**导图外的卡片保持原有行为。选中自由卡片时四周出现 **+**，点击即新建一张用箭头相连的卡片，适合画流程图。**布局 → 自由布局**可让导图回到手动摆放。位于导图之外分组中的卡片会留在原分组。
- **聚焦分支**可淡化其余内容；按 `Esc` 或点击**显示全部**退出。聚焦只是显示状态，不会写入文件。
- **任务进度：**分支中含有任务（`- [ ]`）的卡片会显示一个小圆环和完成数，折叠的卡片和文件卡片所指向笔记中的任务也计算在内；自带待办清单的卡片也显示自己的进度。勾选任务后进度随之更新。
- **演示：**点击工具栏的**演示**按钮（或使用命令），导图会逐个分支讲解：先看整张导图，再按阅读顺序依次聚焦每条主干（中心保持高亮），最后回到整张导图。未选中导图卡片时演示整张白板：按阅读顺序依次展示分组、导图和独立卡片——白板上只有一张导图时，则按分支逐个讲解这张导图。`→`/`空格`/`PageDown` 下一页，`←`/`Shift+空格`/`PageUp` 上一页，`Home`/`End` 跳到首尾，`F` 切换全屏，`Esc` 退出并回到原来的视野。点击卡片可跳到讲解它的那一页。演示不写入任何内容，只读白板也能演示。

导图仍是标准 JSON Canvas：结构记录在中心卡片的 `nfLayout` 字段（非标准间距记录在 `nfSpacing`，单独选择的样式记录在 `nfTheme`，单独选择的连线记录在 `nfLine`，自动配色方案记录在 `nfPalette`），折叠记录在被折叠卡片的 `nfCollapsed` 字段，外框记录在被框住的卡片的 `nfBoundary` 字段，标记记录在卡片的 `nfMarkers` 字段，笔记和链接记录在卡片的 `nfNote`、`nfLink` 字段（多条时为列表），编号开关记录在中心卡片的 `nfNumbering` 字段，关系线记录在连线的 `nfRelation` 字段，概要记录在概要卡片的 `nfSummary` 字段，卡片形状、字号和线宽记录在中心卡片的 `nfShape`、`nfTextScale`、`nfLineWeight` 字段。白板会保留这些字段，其他应用会忽略它们，连线在其中显示为普通曲线。

### 笔记样式

一套**配色方案**加一套**版式**，统一改变 Notion Flow 在笔记中绘制的一切。配色方案决定颜色——文字墨色、高亮、标注、表格、列表与引用的点缀色、行内代码和代码块；版式决定造型——标注、标题、高亮、表格、引用、列表符号、待办、分割线、折叠块、分栏和行内代码的画法。任意配色都可以搭配任意版式。这些只改变显示，Markdown 不会改变。已经上过色的笔记也会一起换装，因为颜色以 `var(--nf-red, #hex)` 和 `rgba(var(--nf-red-rgb, …), .18)` 的形式保存；关闭插件或在其他应用中，它们会回退为「经典」配色。**经典** + **经典**与 1.6 之前的外观完全一致；升级也会保留你的外观：你曾改离旧默认值的设置，会成为你自己的各组件设置。

**自定义各组件。**两个画廊下方的**自定义各组件**为每个组件提供一行设置：**标注样式**、**标题装饰**、**高亮样式**、**表格外观**、**引用样式**、**列表符号样式**、**待办复选框**、**分割线样式**、**折叠块箭头**、**分栏分隔**、**行内代码外观**和**装饰色**。每一项默认都是**跟随版式（…）**，括号里写着当前版式使用的效果；明确选定的值始终优先于版式。在「经典」以外的配色或版式下，如果有组件保留着你自己的设置，这些行上方会列出它们，并提供**全部跟随样式**。**外观**中原有的颜色设置——**列表符号颜色**、**引用条颜色**、**行内代码颜色**、**表格表头底色**和**代码块主题**——都新增了**跟随配色方案**，作为第一项和默认值。**代码块主题**变成了代码卡片画廊，为深色模式设计的主题带有**仅深色**标记。

**切换样式配色…**是命令面板中的快速切换器。配色方案和版式分两组列出，输入文字即可筛选。`↑` / `↓` 在已打开的笔记上实时预览，`Tab` 在两组之间切换，`Enter` 应用当前项（会弹出提示确认，例如「笔记样式：北境 · 线框」），`Esc` 还原为原来的样式。它没有默认快捷键，可在**设置 → 快捷键**中绑定。

**白板。**开启**导图跟随笔记配色**（设置 → Notion Flow → 白板）后，没有自己配色方案的思维导图会使用与笔记配色方案配套的导图配色（上表最后一列），样式面板还会固定一个**跟随笔记配色**方块。这只改变显示，导图自己的配色方案始终优先。

### 外观

- **更简洁的所见即所得渲染**是一组纯显示样式：优化标题、任务、分割线、行内代码、引用和 Mermaid 图表，但不会改写 Markdown；按列表层级循环的符号与编号样式不受影响。实时预览中，非活动行的引用标记会隐藏，进入活动行后恢复显示。
- 实时预览和阅读视图都会按完整列表层级循环样式：无序列表为实心圆、空心圆、方块；有序列表为数字、小写字母、小写罗马数字。实时预览的活动行仍显示可编辑的 Markdown 编号。
- 拖入列表任意深度的代码块、标注和引用会使用真实内容层级，并在源码态与渲染态保持对齐。
- 除非你另行指定，颜色都跟随[笔记配色方案](#笔记样式)：「外观」分组开头有实时预览，其中的颜色设置默认为**跟随配色方案**。
- 还没有内容的标题、列表项、待办和引用会显示浅色占位提示（「一级标题」「列表」「待办」「引用」），与空行提示一样；输入 `## ` 时这一行也不再左右跳动。
- 阅读视图中的宽 Markdown 表格可以横向滚动。
- **隐藏行内 Markdown 标记**（默认开启）可在光标未进入源码时隐藏格式标记；Markdown 链接始终可见，源码模式不受影响。
- **书写时隐藏标题标记**把上面这条延伸到光标所在的那一行：标题的 `#` 不再只是「光标离开后才隐藏」，敲下 `## ` 的瞬间这一行就成为标题，和 Notion 一样，而不是让标记一直杵在正文前面。`#` 后面还没有正文时保持可见——孤零零的一个 `#` 是正在输入的标题。把光标移到正文之前即可重新看到标记，在正文开头按 `Backspace` 可一次删除整个标记、让这一行变回段落。无论哪种情况，Markdown 源码中的 `#` 都原样保留。

转为快捷键可以直接改变光标所在块的类型，手不用离开键盘——与块手柄菜单提供的转换完全相同，数字顺序和修饰键都沿用 Notion（非 macOS 用 `Ctrl+Shift`，因为 `Ctrl+Alt` 在欧洲键盘布局上就是 AltGr，会占用输入 `@` 的按键）。光标会停留在原来的文字上，因此写到一半转换不会打断输入。代码块、表格和分栏骨架没有能描述它们的行前缀，这些快捷键对它们不做任何改动。光标在标注正文行时转换的是该行，在标题行时整块转换——与拖拽手柄选中的范围一致。

另外三个「包一层」的快捷键方向相反：它们不是改写行前缀，而是把整块装进一个容器——转为标注时正文成为框内内容、光标停在空标题上，转为折叠块时首行成为标题，转为代码块时整块被围栏包住、光标停在填语言的位置。数字仍沿用 Notion 的顺序（`7` 折叠块、`8` 代码块），而 Notion 没有的标注用 `C`——标注（Callout）的首字母。已经是该类型的块不会被重复包装：已有标注用类型菜单切换，内部含围栏的块也不会被再加一层围栏。

**在上方插入块**是为实时预览唯一留不出输入位置的场景准备的：笔记开头就是已渲染的标注、表格或代码块。两个插入命令都会按正确的缩进新建空块——在标注内部会带上容器的 `>` 标记——然后打开 `/` 菜单，与左侧边距的 `+` 按钮完全一致。

1.6 起的变化：这两个插入命令原先使用 `Cmd/Ctrl+Alt/Option+Enter`，而那正是 Obsidian 自己的「在新分屏中打开链接」/「在新窗口中打开链接」，所以在链接上会打开新窗格，在别处则毫无反应。现在它们改用 `=`（寓意「添加」）：macOS 上为 `Cmd+Option+=` 和 `Cmd+Option+Shift+=`。Windows 和 Linux 上没有默认快捷键，因为 `Ctrl+Alt` 在许多键盘布局中就是 AltGr，会吞掉你要输入的字符；需要的话可在**设置 → 快捷键**中自行绑定。选中块时，`Cmd/Ctrl+Alt/Option+=` 在所有系统上都能插入，因为此时不会输入文字。

块快捷键可以在**设置 → 快捷键**中修改。**设置 → Notion Flow → 键盘快捷键**列出所有组合键，并可直接跳转到已按 Notion Flow 筛选的快捷键设置；**打开快捷键指南**在一个对话框里列出全部组合键、块选择按键和 Markdown 速记。

**选中块之后**（按 `Esc`、框选或 Alt 拖动），按键作用于整个选区：

| 按键 | 选中块时 |
| --- | --- |
| `↑` / `↓`，`Shift+↑` / `Shift+↓` | 切换到上一个/下一个块 / 扩展选择 |
| `Enter` / `Esc` | 回到选区末尾继续书写 / 清除选择 |
| `Alt/Option+↑` / `Alt/Option+↓` | 上移或下移选中的块 |
| `Tab` / `Shift+Tab` | 所有选中块缩进或反缩进一级 |
| `Cmd+Option+0…9` / `Ctrl+Shift+0…9`，`…+7`、`…+8`、`…+C` | 把所有选中块转为正文、标题、列表、待办或引用，或把选区包进折叠块、代码块或标注 |
| `Cmd/Ctrl+Enter` | 为所有选中块添加或去掉待办框 |
| `Cmd/Ctrl+B` / `I` / `U` | 对所有选中块加粗、斜体或加下划线 |
| `Cmd/Ctrl+C` / `X` / `V` | 复制、剪切，或用剪贴板内容替换选区 |
| `Cmd/Ctrl+D` / `Cmd/Ctrl+A` | 创建副本并选中它 / 选中全部块 |
| `Cmd/Ctrl+Alt/Option+=`，加 `Shift` | 在选区下方 / 上方插入块 |
| `Backspace` / `Delete` | 删除选中的块 |
| `Shift+点击` | 把选择扩展到点击的那一行 |
| 拖动已选中块的手柄 | 移动整个选区；落点闪烁提示块去了哪里 |

**白板命令。**每个导图操作也都是以**白板：**开头的命令——新建主题、新建子主题/同级主题、连接卡片、折叠、聚焦、整理为思维导图/逻辑图/组织结构图/树状图/时间轴、配色方案（**白板：配色方案 · …**）与导图样式、**白板：为此分支上色…**、**白板：为全部分支自动上色**、标记、编号、卡片笔记与链接、概要、外框、**白板：在导图中查找文字**、**白板：跳转到卡片…**、演示、由笔记生成导图、分支导出为笔记等。它们都没有默认快捷键；选中卡片时可用的按键见上方的白板按键表。

## 会写入 Markdown 的内容

大多数操作会生成标准 Markdown。下划线、文字颜色和彩色高亮使用内联 HTML，代码块内的所有格式（`<b>`、`<i>`、`<s>`、`<u>`、颜色 span）同样如此。颜色写作 `var(--nf-名称, #十六进制)`（高亮写作 `rgba(var(--nf-名称-rgb, …), .18)`），在插件下跟随笔记配色方案和浅色/深色墨色，缺少插件样式表时回退到「经典」配色的那个值。表格、单元格和公式颜色使用由 Notion Flow 样式表渲染的少量 class 标记。这些标记会保留在笔记中，因此可以随同步和复制粘贴保存；但在 Obsidian 之外或未启用插件时，不保证保留相同的颜色外观。

其他写入形式：

- **说明文字：**代码与图片的说明文字使用紧随块后的可读 `<small class="nf-caption">…</small>` 行，代码的说明文字行还保存折叠状态——没有 Notion Flow 时仍是普通小号 HTML 文本，折叠元数据也不会影响正文。
- **图片：**尺寸是 Obsidian 自己的 `![[image.png|480]]` 宽度，对齐是嵌入语法中的 `left`、`center` 或 `right` 一词（`![[image.png|center|480]]`）。
- **标注：**标注颜色是标题元数据中的 `nf-颜色` 标记（`> [!tip|nf-green]`），标注图标是 `nfi-名称` 标记（`> [!tip|nfi-rocket]`），或 `nfi-emoji` 加标题开头的表情；其他应用都会忽略它们。
- **分栏**是嵌套标注（`[!nf-cols]` / `[!nf-col]`），在其他应用中降级为普通嵌套引用；**折叠块**是带 `+`/`-` 折叠标记的 `[!nf-toggle]` 标注。
- **批注**是带 data 属性的 span，在其他应用中锚文本正常显示、批注内容不可见。
- **块颜色：**文字颜色把块的每一行包进颜色 span；背景色是块第一行末尾（任何 `^块ID` 之前）的一个空标记 `<span class="nf-blk-blue"></span>`。
- **页面：**页面图标与封面是 `icon`、`cover`、`cover-style` 和 `cover-y` 属性，页面样式是 `cssclasses` 属性中的 `nf-serif`、`nf-mono`、`nf-kai`、`nf-small` 或 `nf-wide`。
- **目录：**`/toc` 写入 `<!-- nf-toc -->` 标记，其后是由 `[[#…]]` 链接组成的普通嵌套列表。标题中的 `|` 在链接文字里显示为 `｜`（实时预览会隐藏双链内的所有 `|`），标题末尾的块 ID（` ^id`）不会显示。

配色方案和版式不会向笔记写入任何内容——它们只是设置。**导图跟随笔记配色**不会写入 `.canvas` 文件，**存为我的配色**保存在插件设置中。

Notion Flow 不会上传笔记内容。启用**粘贴 URL 自动获取标题**时，粘贴链接会向该 URL 发送一次请求以读取标题；关闭该设置即可完全离线。打开文档或示例时会使用浏览器，**复制文本**功能会使用系统剪贴板。

## 故障排查与限制

- **没有块手柄：**请使用桌面端实时预览，并确认已启用**块拖拽**。
- **没有表格工具栏：**请启用**浮动格式工具栏**。**表格编辑增强**控制的是原始表格快捷键和右键菜单，不控制该工具栏。
- **没有白板工具栏或分支快捷键：**请开启**白板增强**，在画布中选中一张卡片；快捷键还需要开启**白板快捷键**，且在编辑内容时不会接管按键。白板功能依赖 Obsidian 内部接口，Obsidian 更新后可能需要适配。
- **卡片意外加入了导图：**从导图卡片连出的无标签连线会让目标卡片成为分支。给这条连线加上标签即可变为关系线，或改为从另一张卡片连出。
- **`Tab` 或 `Enter` 没有使用 Notion Flow 导航：**增强快捷键只作用于原始 Markdown 表格，不作用于 Obsidian 已渲染的单元格编辑器。
- **工具栏无法格式化渲染组件内的选区：**Obsidian 在已渲染标注或彩色文字中可能只提供 DOM 选区。请先打开组件源码，或把选区扩展到普通编辑器文本。
- **旧笔记中的嵌套标注显示成代码：**将光标放在标注源码上，执行**Notion Flow: 修复列表内标注（Callout）**。该修改可以撤销。
- **插入块的快捷键没反应或打开了分屏：**1.6 起这两个快捷键已改为 macOS 上的 `Cmd+Option+=` / `Cmd+Option+Shift+=`，其他系统默认不绑定。请在**设置 → 快捷键**中检查是否有自定义绑定。
- **没有页面图标或封面：**请开启**页面图标与封面**，关闭 Banners、Pixel Banner 或 Iconize 插件，并使用实时预览或阅读视图。
- **配色方案只部分生效：**第三方主题可能不跟随**纸张底色：整个界面**（它为默认主题设计），可以改用**笔记页面**。配色方案只改变 Notion Flow 绘制的内容，其余部分仍由你的主题决定。
- **模板条目提示未配置模板文件夹：**请开启核心插件「模板」，并在**设置 → 模板 → 模板文件夹位置**中设置。
- **手动安装后找不到插件：**确认目录为 `.obsidian/plugins/notion-flow/`，其中包含三个发布文件，然后重启 Obsidian。

## 语言

界面会跟随 Obsidian 的语言设置，内置英文和简体中文。无论使用哪种界面语言，斜杠搜索都接受中英文关键词，中文名称还支持拼音全拼和首字母。**设置 → Notion Flow → 帮助与示例**中提供两种语言的文档和示例按钮。
