# Notion Flow — 10 分钟上手

[English version](notion-flow-demo.md) · [样式样张](notion-flow-style-demo.md)

> 将本文档复制到 Obsidian 库中，再创建一份练习副本，并在桌面端使用**实时预览**打开。下文用到的大多数功能已在**设置 → Notion Flow** 中默认开启。

## 1. 移动和创建内容块

悬停本段。拖动 `⋮⋮` 可移动整个段落，点击 `⋮⋮` 可打开块菜单，点击 `+` 会在下方创建内容块并打开斜杠菜单。

拖动时左右移动指针，可以改变嵌套层级。试着移动下面的父列表项，其中的嵌套内容会一起移动。

- 一个项目进展
	- 初稿已经完成
	- 评审已经排期

  ```ts
  const project = { status: "ready" };
  project.status;
  ```

  > 嵌套引用会与父列表项保持对齐。

  > [!tip] 嵌套标注
  > 标题和正文会作为一个完整内容块移动。

单击手柄而不拖动，试用**转为**、**创建副本**和**复制文本**。只对不介意移除的内容使用**删除块**。

块菜单里还有**块颜色**（文字或背景）、**移动到…**和**转为页面**。在列表项上点击 `+` 会新建下一个列表项。

如需一次操作多个块，可以从上方行旁的空白处拖出选框，也可以按住 `Alt/Option` 从编辑区任意位置开始拖动。出现的浮动工具栏会一次转换所有选中的普通块；表格、围栏代码块和多行引用会被跳过，以保持其结构完整。按 `Esc` 或点击 × 可清除选择。

## 2. 用键盘选择块

点进下面第一段练习文字，按 `Esc`：整个块被选中。然后：

- `↑` / `↓` 切换到上一个或下一个块，`Shift+↑` / `Shift+↓` 扩展选择。
- `Alt/Option+↑` / `↓` 移动选中的块，`Cmd/Ctrl+D` 为它们创建副本，`Backspace` 删除它们。
- `Cmd/Ctrl+Alt/Option+=` 在选区下方插入块（加 `Shift` 为上方），并打开斜杠菜单。
- `Enter` 回到选区末尾继续书写；再按一次 `Esc` 清除选择。

## 3. 使用斜杠命令插入内容

把下面的练习文字替换成 `/`，然后继续输入以筛选菜单。中英文关键词都可以使用，中文名称还支持拼音首字母，例如 `/zw` → 正文。

练习行——在这里输入 `/`。

常用搜索包括 `/h1`、`/h2`、`/h3`、`/bullet`、`/number`、`/todo`、`/quote`、`/callout`、`/toggle`、`/code`、`/table`、`/divider`、`/image` 和 `/link`。标注类型和颜色可以直接按名称搜索：`/tip`（或 `/提示`）插入提示标注，`/red background`（或 `/红色背景`）给块加上红色背景。`/toc` 根据本笔记的标题生成目录；开启核心插件「模板」后，`/template` 会列出模板文件夹中的笔记。

用鼠标或 `Enter` 选择**表格**都会打开尺寸网格：在网格上拖动或用方向键调整，再按 `Enter`。在命令里直接写上尺寸（`/table4x6`）即可跳过网格。

## 4. 编辑表格

点击下面已渲染表格中的单元格，打开表格工具栏。

| 任务 | 负责人 | 状态 |
| :--- | :--- | :---: |
| 整理文档大纲 | 小林 | 已就绪 |
| 检查示例 | 小梅 | 进行中 |
| 发布指南 | 小周 | 未开始 |

试试这些操作：

- 新增一行或一列，然后再删除。
- 设置当前列的对齐方式。
- 设置单元格底色和表格底色，再移除其中一种颜色。
- 选择**格式化表格**。
- 按 `Alt+F10`，再用左右方向键在工具栏按钮之间移动。
- 点击表格的 `⋮⋮` 手柄，打开整表操作或移动完整表格。
- 在表格内右键：所有表格操作都在**表格**子菜单中。

### 原始 Markdown 表格练习

下面的导航只作用于**源码模式**中的表格，或仍未渲染的原始 `|` 表格。

1. 在空行中输入 `| 名称 | 数量`，按 `Tab` 自动补全表格结构。
2. 使用 `Tab` 和 `Shift+Tab` 在单元格之间移动。
3. 使用 `Enter` 移动到当前列的下一行。
4. 从最后一个单元格继续导航，自动追加一行。
5. 在空的最后一行按 `Enter`，移除该行并离开表格。

## 5. 设置文本格式

选中下一句话的一部分。使用浮动工具栏设置粗体、斜体、下划线、删除线、文字颜色、高亮、行内代码或链接，最后再试试**清除格式**。

选中并格式化这句话，全程不离开实时预览。

标准 Markdown 示例：**粗体**、*斜体*、~~删除线~~、`行内代码`、==高亮==和[外部链接](https://obsidian.md/)。

`Cmd/Ctrl+K` 打开链接卡片，可在其中编辑文字和目标（附带笔记建议）；`Cmd/Ctrl+U` 添加下划线。

如需尝试粘贴 URL，请选中文字“Obsidian 帮助”，然后粘贴 `https://help.obsidian.md/`。启用**粘贴 URL 生成链接**后，选中文字会变成 Markdown 链接。

启用**隐藏 HTML 格式标签**后，实时预览会隐藏下划线和颜色标签。**隐藏行内 Markdown 标记**默认开启：光标进入时才显示 `**` 等标记；可以关闭后比较两种编辑方式。

## 6. 批注

这句话上有一条<span class="nf-cmt" data-nf-cmt="批注保存在笔记里，在其他 Markdown 应用中不可见。">批注</span>——悬停这几个字或其后的 💬 即可阅读，再试试「编辑」和「解决」。

在这一行选中几个字，按 `Cmd/Ctrl+Shift+M`（或工具栏的 💬 按钮）添加你自己的批注。

在命令面板中运行**查看本笔记的批注**，列出所有批注：`Enter` 跳转到所选批注，`Cmd/Ctrl+Enter` 解决它。

### Mermaid 图表和代码主题

```mermaid
flowchart LR
  A[草稿] --> B{评审}
  B -->|通过| C[发布]
  B -->|需修改| A
```

启用**更简洁的所见即所得渲染**后，上方图表会渲染在适配当前主题的卡片式画布中。宽图会保留可读字号并支持横向滚动，不再被压缩；聚焦图表后可使用键盘或触控板滚动。

围栏代码块——例如第 1 节中的 `ts` 代码块——使用**代码块主题**，默认为**跟随配色方案**（配色方案为「经典」时使用当前主题的颜色）。在设置的主题卡片中选一个即可单独指定。

## 9. 快捷键和快捷键指南

将光标放到下面的练习段落中。

- `Alt/Option+↑` 或 `Alt/Option+↓` 移动内容块。
- `Alt/Option+Shift+D` 创建块副本。
- `Cmd+Option+1`（Windows 和 Linux 上为 `Ctrl+Shift+1`）把它转为一级标题；`…+0` 转回正文。
- 在 macOS 上，`Cmd+Option+=` 在它下方插入块并打开斜杠菜单，`Cmd+Option+Shift+=` 在上方插入。Windows 和 Linux 上这两个命令没有默认快捷键。
- 可以在 Obsidian 的**快捷键**设置中重新绑定这些块快捷键。

练习段落——移动我，或为我创建副本。

**打开快捷键指南**（在命令面板中，或在**设置 → Notion Flow → 键盘快捷键**中）列出所有组合键、块选择按键和 Markdown 速记。

## 10. 白板思维导图

把[白板示例](canvas-flow-demo.canvas)复制到库中本笔记旁边并打开（需要开启**白板增强**）。

- 选中一张卡片：`Tab` 新建子主题，`Enter` 新建下一张，`Shift+Enter` 在上方新建同级主题。
- 在卡片中输入时，`Enter` 结束编辑并保持选中——再按 `Enter` 新建下一张，或按 `Tab` 新建子主题。`Shift+Enter` 换行。
- 工具栏的**样式**面板提供配色方案；没有配色方案的导图会跟随笔记配色（**导图跟随笔记配色**）。
- 工具栏末尾的 **?** 打开**白板导图指南**。

## 11. 如果功能没有出现

- 块手柄需要桌面端实时预览，并启用**块拖拽**。
- 文本和就地表格工具栏需要启用**浮动格式工具栏**。
- 原始表格的 `Tab` 和 `Enter` 行为需要启用**表格编辑增强**。
- 批注、分栏和折叠块各有自己的设置：**批注**、**分栏**和**折叠块**。
- 页面图标与封面需要开启**页面图标与封面**。
- 配色方案和版式只改变插件绘制的部分——窗口的其余部分仍由 Obsidian 主题决定。
- 完全位于已渲染标注或彩色文字中的选区可能无法映射回编辑器。请打开其源码，或把选区扩展到普通编辑器文本。
- 如需重新开始，请使用**设置 → Notion Flow → 恢复默认设置**，然后用原始示例替换当前练习副本。
